# Desafio Técnico - Desenvolvedor/a de Sistemas Jr.

Solução desenvolvida em C# para o desafio técnico.

## Exercícios

### Exercício 1
Leitura de dados de vendas em JSON e cálculo da comissão total de cada vendedor.

### Exercício 2
Movimentação de estoque com operações de entrada e saída, identificação das movimentações e atualização da quantidade em estoque.

### Exercício 3
Cálculo de juros com base no valor informado, data de vencimento e taxa diária.

## Tecnologias utilizadas

- C#
- .NET
- System.Text.Json
